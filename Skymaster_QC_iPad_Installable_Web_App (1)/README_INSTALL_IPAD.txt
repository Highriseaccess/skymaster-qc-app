SKYMASTER QC — IPAD INSTALLABLE WEB APP

This is a ready-to-host progressive web app, NOT an .ipa file.

INSTALL ON IPAD
1. Upload all files in this ZIP to the same folder on an HTTPS website (such as GitHub Pages).
2. Open the HTTPS link ending /index.html using Safari on iPad.
3. Tap the Safari Share icon > Add to Home Screen > Add.
4. Launch the Skymaster QC icon from the Home Screen.
5. After the initial online opening, the service worker caches the app for offline use.

PDF: Tap Save PDF, then use Share > Save to Files.
INSPECTION BACKUP: Use Export inspection file to preserve a JSON copy, especially with photos.

CAUTION: Data is saved locally on the specific device. It is NOT cloud-synced. Clearing site data or deleting the app can delete its saved inspections.

Do not open index.html directly from the Files app if you want the installable Home Screen experience.
